# Project Context

Эта папка содержит только подтверждённые знания конкретного проекта. Универсальные QA-правила находятся в `../qa/`.

Заполняйте факты с указанием source/reference. Не копируйте сюда предположения LLM. Если информация неизвестна, оставляйте `UNKNOWN` или ссылку на источник, который должен быть получен.

## Context catalog

После заполнения project context поддерживайте `qa-context/context-catalog.yaml`: добавляйте новые sections/tags, чтобы `qa-flow` мог делать selective retrieval без чтения всех файлов.
